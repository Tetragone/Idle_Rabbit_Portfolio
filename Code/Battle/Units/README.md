# 플레이어 스킨 적용 어댑터

`PlayerUnitSkinAdapter`는 플레이어 로직과 외부 스킨 빌더 사이에 둔 직접 작성 코드입니다. 장비 변경 코드가 빌더 세부 설정과 재생성 절차를 각각 알지 않도록 적용 단계를 모았습니다. 작성자는 이 단계를 추가한 뒤 변경해야 할 코드의 범위가 줄어든 경험을 설명합니다. 구체적인 감소 줄 수는 측정 자료가 없어 기재하지 않습니다.

원본의 방어구 적용은 Armor·Helmet 설정 → 빌드 대기 → 초상화 갱신 → 완료 표시, 무기 적용은 Weapon 설정 후 같은 절차입니다. PlayerUnit은 이 어댑터에 무기 적용을 요청하고 준비 상태를 확인합니다.

원본의 NewPlayerUnitBuilder, NewSpriteLayer, NewSpriteCollection과 스킨 에셋은 작성자의 코드가 아니므로 제외했습니다. 공개본 어댑터는 새로 정의한 IPlayerSkinBuilder 계약을 참조합니다. 이 계약은 외부 구현을 재현한 빌더가 아니라 호출에 필요한 속성과 메서드의 선언입니다. 실제 구현을 제공하지 않습니다.

공개용 수정 전후는 SourceManifest에 기록합니다. 계약이 연결되지 않았을 때 빌드 완료인 것처럼 처리하지 않고 예외를 던집니다. 캐릭터 스킨 교체가 동작하는 실행 샘플로 소개하지 않습니다.
