# 로그라이크 탐험 던전

기존 스테이지·풀·전투 코드에 웨이브 진행과 선택 효과를 추가한 구현입니다. 별도 진행 저장 파일을 만들지 않고 한 번의 도전을 RoguelikeStage 객체가 관리합니다. 앱 종료 후 도전 재개는 제공하지 않습니다.

작성 방식은 **AI 생성 기반**입니다. 작성자가 기능·정책·수정 방향을 구체적으로 설명하고 결과를 확인·조정하며 반영했습니다. 공개본에서 직접 작성한 코드로 바꾸어 소개하지 않습니다.

## 상태와 웨이브

`Preparing → Fighting → Selecting → Preparing`을 반복하고 마지막 웨이브 이후에는 `RewardPending → Ended`로 진행합니다. 실패하면 Ended로 이동합니다. 보유 한도로 보상을 지급하지 못하면 RewardPending에 머물며 다른 전투로 전환하지 않습니다.

테이블의 단계·웨이브 순서는 1부터 연속이어야 합니다. 최초 조회에서 전체 설정을 검증하고 성공한 결과만 캐시합니다. 구성 단계는 `(실제 단계 - 1) % 구성 개수 + 1`이며 적 능력치·보상·최고 기록은 실제 단계 기준입니다. 캐시에는 읽기 전용 인터페이스로 접근하지만 데이터 객체 자체가 불변인 구현은 아닙니다. 실행 중 테이블 재로드는 지원하지 않습니다.

KillAll은 전체 생성 완료와 생존 적 0을 검사하며 반복 생성과 함께 사용할 수 없습니다. Survive는 제한 시간 동안 생존하면 통과하며 반복 생성을 허용합니다. 생성 주기마다 생존 한도의 빈자리만큼 생성하고 일반 적은 플레이어 주변의 고리 영역, 보스는 고정 위치에 배치합니다.

WaveSpawner는 AliveEnemies와 OwnedEnemies를 구분합니다. 처치되면 생존 목록에서 제거하지만 사망 연출 중인 객체는 웨이브 정리 때 회수할 수 있도록 보관합니다. 회수 시 생성 당시 ID와 현재 ID, 활성 상태를 검사해 풀에서 다른 소환으로 재사용된 객체를 다시 반환하지 않도록 합니다.

## 선택과 임시 스탯

최대 중첩에 도달한 ID를 제외하고 가중치에 따라 최대 3개의 서로 다른 후보를 뽑습니다. 한 후보를 뽑을 때 ID와 가중치를 함께 제거합니다. 후보가 1~2개이면 남은 수만 표시하며, 팝업을 다시 연다고 재추첨하지 않습니다.

유효한 후보인지와 선택 상태인지는 스테이지가 검사합니다. 팝업은 스테이지 객체와 웨이브 번호를 기억하고 선택 시 현재 도전과 대조합니다. UI_Game은 비동기 로딩 이후 화면 활성 상태·요청 버전·현재 스테이지·웨이브·선택 상태를 다시 검사합니다.

선택 효과는 PowerMgr.PlayerStat에서 시작해 매번 다시 계산합니다. 같은 능력치 증가율은 합산하며 영구 성장 데이터를 변경하지 않습니다. 최대 체력 효과를 선택한 순간만 증가한 최대 체력만큼 현재 체력을 보충합니다. 웨이브 사이에 플레이어 전체를 재초기화하지 않아 체력·마나·쿨타임을 유지합니다.

전투 정지는 BattleMgr.IsCombatPaused와 BaseUnit·PlayerUnit·BaseMissile의 검사로 연결합니다. 웨이브 통과 시 WaveCombatCleared 알림으로 투사체를 회수하고 플레이어 타깃을 초기화합니다. 구독 해제는 BaseMissile.RegistAction에서 함께 처리합니다.

## 보상과 결과 표시

RoguelikeStage.TryCompleteReward는 실제 보상을 지급한 뒤 최고 기록과 퀘스트를 갱신합니다. 현재 성공 보상 계산은 DropCalculator의 RogueDungeon 분기입니다. 실패 비용은 현재 코드상 ActionPopup의 공통 실패 경로에서 차감합니다.

현재 결과 UI는 일반 Popup_Common 경로이며 다음 도전·돌아가기 버튼을 제공합니다. 원본 문서에 있던 로그라이크 전용 결과·자동 복귀 설명을 이 공개본의 동작으로 옮기지 않았습니다. 성공 표시 목록에 입장권을 추가하는 ActionPopup 코드와 실제 지급 목록은 별도로 검토해야 합니다. 이 차이를 공개 준비 과정에서 게임 정책 변경으로 수정하지 않았습니다.

## 설정과 공개 범위

[테이블 컬럼과 가상 예시](../../docs/RoguelikeTables.md)를 제공합니다. 원본 CSV, 적·플레이어 스킨, 외부 폰트와 이미지, Addressables 설정과 씬은 제공하지 않습니다. 기존 공개용 대체 연결을 유지하므로 실행 가능한 던전 샘플이 아닙니다.

선택 팝업·카드, 전투 HUD·던전 진입 프리팹은 외부 리소스 참조를 비워 포함했습니다. 로그라이크 전용 자동 검사 코드는 포함하지 않으며 컴파일·정적 검사와 실제 게임 실행 검증을 구분합니다.
