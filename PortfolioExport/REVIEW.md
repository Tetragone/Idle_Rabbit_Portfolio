# 공개본 작업 보고

작성일: 2026-11-24

## 준비한 내용

- 이벤트·장비·Soul UI 전체와 핵심 기능, 호출에 필요한 보조 코드: C# 119개.
- 기존 레이아웃을 보존하고 외부 리소스 참조를 비운 UI 프리팹: 22개.
- 기능별 README, 의존성과 작성 기여, 제외 목록, 원본 대응 경로·해시, 프리팹 참조 변경 기록.
- 공개본에서만 테이블 공급, 메모리 저장, 사운드 알림, 스킨 빌더 계약과 Atlas 미연결 처리를 적용.

## 수행한 확인

- `Tools/check_export.py`로 허용 파일, 제외 코드의 의존성, GUID 중복·누락, 프리팹 내부 fileID, 문서 링크, 원본 대응 목록과 공개본 해시를 확인.
- 로컬 Unity 6000.4.0f1의 참조 DLL과 Roslyn C# 컴파일러로 공개 C# 119개와 Editor 검사 코드를 함께 컴파일. 원본 Assembly-CSharp와 Assembly-CSharp-Editor DLL은 참조에서 제외. 컴파일 종료 코드 0.
- 원본 프로젝트의 추적 파일에 변경이 없는지 Git diff와 선별 원본 파일의 SHA-256으로 확인.

컴파일 과정의 응답 파일·DLL·로그는 공개 폴더에 포함하지 않습니다. 원본 런타임·에디터 프로젝트의 중복 참조 DLL을 한 개씩 선택한 로컬 검사이며, 배포용 Unity 프로젝트 빌드가 아닙니다.

## 수행하지 않은 확인

- Unity Editor에서 공개본을 임포트하고 실행하는 검사.
- 이벤트·퀘스트·Virtualized List 검사 메뉴의 실제 실행.
- 실제 UI 배치·버튼·폰트·스크롤·팝업·스킨·Addressables 동작.
- 재접속 저장·디스크 파일 입출력·기기 동작·성능 측정.
- 원본 Git 과거 전체 blob이나 제외한 바이너리에 대한 비밀 탐지.

이 자료는 코드 열람용입니다. 프리팹의 참조를 정리했지만 화면 검증을 마친 리소스로 소개하지 않습니다. TMP 기본 폰트 지정, 제거된 애니메이션을 사용하는 UI 처리와 전체 초기화 환경은 별도 구성 대상입니다.
